# GOL RADAR

Kişisel canlı maç tarayıcısı. GitHub Pages için dosyalar depo kök dizinindedir.

- Canlı maçlar ESPN'in herkese açık fakat gayriresmî uç noktalarından alınır.
- Erişilebilen 18 lig kontrol edilir; tüm dünya liglerinin garantili kapsamı yoktur.
- İstatistik bulunan maçlar baskı puanına göre yüksekten düşüğe sıralanır.
- 85/100 sezgisel baskı puanıdır, gol olasılığı veya başarı yüzdesi değildir.
- Uygulama açık ve görünürken 60 saniyede bir yenilenir. Kapalıyken arka plan takibi yoktur.
- Tahmin/bahis/kazanç garantisi vermez.
